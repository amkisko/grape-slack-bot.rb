# Release 3.0.1

## Participants

Andrei Makarov (@amkisko)

## Decisions

- Cut 3.0.1 as a patch for the empty Slack acknowledgement body under Grape JSON format.
- Keep the Ruby 4.0.10 / 3.4.13 interpreter pins out of `CHANGELOG.md`; the published gem contract stays `required_ruby_version >= 3`.
- Align the version in the library, the root lockfile, and all four Appraisal lockfiles.
- Leave tag and RubyGems publish to `make release` after a clean commit.

## Effects

- `CHANGELOG.md` contains the 3.0.1 section dated 2026-11-19.
- `VERSION` is 3.0.1. PATH gem entries in `Gemfile.lock` and appraisal lockfiles point at 3.0.1.
- `gem build grape-slack-bot.gemspec --output tmp/release/3.0.1/grape-slack-bot-3.0.1.gem`
  built a 35328-byte package with 39 files. `Gem::Package#verify` passed.
  The extracted package loaded version 3.0.1. `shasum -a 256 -c SHA256SUMS` passed in `tmp/release/3.0.1`.
- `BUNDLE_FROZEN=1 POLYRUN_COVERAGE=1 make test` passed with a writable
  `RUBOCOP_CACHE_ROOT`. RuboCop checked 77 files and all five test shards
  passed. RBS emitted the existing Ruby 4.1 `tsort` warning.
- `bundle exec rspec spec/slack_bot/grape_extension_spec.rb` returned 52 examples and zero failures.
- `BUNDLE_FROZEN=1 BUNDLE_GEMFILE="gemfiles/$appraisal.gemfile" bundle exec rspec --format progress`
  returned 420 examples and zero failures for `rails72`, `rails8ruby34`, and `rails8ruby4`.
- `git diff --check` passed. Release version check accepted the 3.0.1 changelog notes.

## Next

- Commit the working tree, push `main`, then run `make release` to test, push the gem, tag `3.0.1`, and create the GitHub release.
