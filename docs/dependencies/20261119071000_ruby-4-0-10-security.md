## Dependency

- Ruby MRI runtime pin
- Base: 4.0.2 (`.ruby-version`)
- Target: 4.0.10
- CI companion floors: 3.4.13 on the 3.4 jobs; 4.0.10 on the MRI 4.0 job
- Tier: hot path (process runtime for library, CI, and local probes)

## Symptom

Local and CI MRI pins below 4.0.10 / 3.4.13 remain on advisory-affected interpreters. Ruby 4.0.0 through 4.0.9 and Ruby 3.4.0 through 3.4.12 are named in the 2026-11-18 Regexp and String case-conversion advisories. Earlier 4.0.x security releases between the base and target also remain missing on 4.0.2.

## Evidence

- Upstream advisory: https://www.ruby-lang.org/en/news/2026/11/18/multiple-vulnerabilities-in-regexp-and-string/
- Release notes source: https://github.com/ruby/ruby/releases/tag/v4.0.10
- GHSA IDs fixed in 4.0.10: GHSA-34m4-m9fh-gqp5, GHSA-7x2q-68qv-6p8x, GHSA-87fm-7w84-j2px, GHSA-wpqw-5qxg-m68r, GHSA-3p8q-wmhx-vm2w, GHSA-7whj-cfh7-xgm4, GHSA-pvgc-g7gj-pv6h
- Earlier interval security notes: 4.0.3 ERB CVE-2026-41316; 4.0.5 CVE-2026-46727 getaddrinfo use-after-free; 4.0.8/4.0.9 Regexp compilation fixes tied to GitLab CVE-2026-89078, CVE-2026-93577, CVE-2026-97229, CVE-2026-110264
- This tree uses fixed Regexp literals in `lib/` (`ApiClient::TOKEN_FORMAT`, `ResponseUrl::PATH`, command token escape). Schema specs call `upcase` on fixture values. Faraday resolves Slack hosts (getaddrinfo path). ActiveSupport is a runtime dependency and can load ERB in host apps.

## Suggested fix

Upgrade the local pin to 4.0.10. Pin CI MRI jobs to 4.0.10 and 3.4.13. Do not ship 4.1.0-preview1.

## Trigger

- User request to upgrade Ruby to latest with changelog, vulnerability, and resource compare checks on 2026-11-19.
- Published 2026-11-18 Ruby security releases.

## Advisory

- 2026-11-18 Regexp and String case-conversion set (seven GHSA IDs; CVE IDs requested, not assigned at record time)
- Prior interval: CVE-2026-41316 (ERB), CVE-2026-46727 (getaddrinfo), GitLab-linked Regexp CVEs fixed in 4.0.8/4.0.9
- CISA KEV: not checked as listed for these GHSA IDs at record time

## Status

- Local pin and CI MRI pins: fixed after `.ruby-version` and workflow patch pins land on 4.0.10 / 3.4.13
- Published gem execute path on unpatched host Ruby: affected until the host upgrades

## Applicability

- Vulnerable interpreter present on base 4.0.2 and on CI 3.4 / 4.0 minor-line pins before the patch floors
- Case-conversion and Regexp bugs can execute in the MRI process. Attacker-controlled patterns are not compiled from Slack input in this library's own `lib/` paths (`not_used` for `Regexp.new` on request bytes). Case conversion of attacker-controlled strings remains credible via host ActiveSupport or app code on the same interpreter. Faraday DNS uses getaddrinfo (CVE-2026-46727 class). Disposition stays upgrade for the runtime pin.

## Priority

- High for local and CI MRI pins because several advisories describe RCE PoCs and the interpreter is shared with host apps.

## Disposition

- Upgrade runtime pin and CI floors. No gemspec floor change required for this security set.

## Next
